# Zalim-Marketing Portfolio

This repository contains the responsive Zalim-Marketing portfolio website. It is a static React and Vite application with locally bundled, optimized portfolio visuals.

Run `pnpm install` followed by `pnpm dev` for local development. Run `pnpm build` to create the production static site in `dist/public`.

To publish with Vercel, import the repository, keep the detected Vite framework settings, and deploy. The included `vercel.json` sets the build command, output directory, and single-page application rewrite.
